## 语言模型的发展方向

- **顺序到并发**：顺序是计算机架构带来的本质属性，并发才是真实世界的样子。
- **由瘦到肥**：语言中特性和概念的多寡，直观体现为关键词的多少、支持的开发范式种类以及语言的复杂程度。例如 ANSI C 与今天的 C99——后者引入了更多新概念。

语言的表现力是一把双刃剑：特性越多、表现力越强，实现复杂算法就越简洁，但理解难度也相对更高、滥用的可能性也越大。

作者在《[Concepts, Techniques, and Models of Computer Programming](https://webperso.info.ucl.ac.be/~pvr/book.html)》原本的模型树上，又增加了更多的模型。

## Core：几乎所有语言共有的部分

### 数据类型（Type）

基础类型：

| 类型 | 举例 | 说明 |
| --- | --- | --- |
| 数字类型 | `int`、`float` | |
| 字符串类型 | `string`、`char` | |
| 符号类型 | `symbol`、`enum` | 一些语言中也称为 atom |
| 函数类型 | `(int, int) -> int` | 参数类型和返回值类型的组合 |
| 其他类型 | `bool`、`byte` | |

组合类型：

- **tuple（广义）**：例如 array、list、map
- **抽象数据类型（ADT）**：List、Stack、Queue、Deque、Set、Map、Graph、Tree

其他类型：计算领域的复数和矩阵等。

### 变量（Variable）

需要变量来承载类型的值。声明变量时，有些风格是赋值即声明，另一些则区分声明与赋值。变量的可变性，引出了两类完全不同的模型。

### 函数（Function）

函数本身也是一种变量。操作符是函数调用的一种语法糖。

### 表达式（Expression）

变量、函数和操作符共同构成表达式，表达式可以求出一个值。

### 语句

不是所有语言共有的概念，但大多数语言都会在表达式的基础上引入各种语法关键词组成语句，进而通过表达式和语句的堆叠与嵌套来定义函数。

### IO

与外界进行通信。

## 声明式模型（Declarative Model）

最简单、最实用的模型，也是大部分现代语言的基础。它关注 *what* 而不是 *how*——需要表明做什么，而不是指定怎么做。

```text
Declarative programming
├── Descriptive          纯描述性，HTML，最简单
└── Programmable         可编程语言
    ├── Observational    可被观察（interface 的定义和暴露），protobuf
    └── Definitional     可被定义，编写可运行程序的语言
        ├── Declarative model
        ├── Functional programming
        └── Logic programming
```

### 模型的必要组成部分

在 Core 的基础上，它额外加入了**变量**、**函数**和**分支判定**这三个概念。

#### 变量

引入了变量绑定和解构（destructuring）。变量绑定是把右侧的只绑定到左侧的对象，也被称为赋值；在 declarative model 中，变量一旦绑定，其值不可修改。解构则是进行若干次赋值，使左右两边表达式相等。

变量声明也有不同风格：声明变量是单独的语句，或者声明变量的同时也创造了一个代码块。

#### 函数的声明和调用

函数的声明和调用几乎统一，只有细微的风格差别：

- 声明时指定：函数名（可选）、参数列表、返回值类型（可选）、函数体
- 调用时指定：函数名或函数本体、参数列表

函数可以随处定义，甚至嵌套定义。

#### 分支判定

`if/else`、`switch/case`、`match/case`。

#### 一个值得注意的限制

declarative model 不支持循环。
