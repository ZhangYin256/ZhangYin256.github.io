去年开始正经练，最初的问题不是“不想练”，而是“不知道今天该练什么”。这份笔记整理自 B 站《健身新手的训练完全手册》，主要给未来的自己复习用。

## 训练分化

- **五分化**：背、胸、肩、手、腿
- **四分化**：背+肩后束、胸+肩前中束、手、腿
- **三分化**：背+肩后束+肱二头、胸+肩前中束+肱三头、腿

循环速度越细分越慢，单部位训练组数越多。三分化和四分化比较兼顾循环速度和训练组数，适合绝大部分人；二分化适合新手，五分化适合职业选手中的一部分人。

训练频率会限制分化：每周只练一两次不太可能练出肌肉，最好每周三到五次，那就选三分化或四分化。另外，每天的训练部位不是任意组合，要利用肌肉间的协同关系。

### 三分化

- Day1：背 + 肩后束 + 肱二头
- Day2：胸 + 肩前中束 + 肱三头
- Day3：腿 + 腹

### 协同肌群

#### 胸 + 肩前束 + 肱三头

推胸类动作：杠铃卧推（躺）、坐姿器械推胸（坐）、双杠臂屈伸（趴、俯身）、俯卧撑（趴）。

当推胸训练把胸肌练到十成之后，肩前束、肱三头至少已经有了六成热度。三四分化继续补练协同肌群：

- 先练胸：杠铃平板卧推、史密斯上斜卧推、坐姿器械推胸
- 补练肩前束：坐姿哑铃推举、站姿哑铃前平举
- 补练肱三头：仰卧杠铃臂屈伸、站姿绳索臂屈伸

#### 背 + 肩后束

划船类动作分两类：

- 下背划船（拉向下背，指腹部）：俯身哑铃划船、坐姿钢线划船
- 上背划船（拉向胸口）：俯身杠铃划船、T 杆划船

## 动作模式

具体动作归属于特定的动作模式。搞清楚模式，比记住动作名有用得多。

### 肩关节与胸背肩的关系

- **水平面**
  - 水平内收：大臂在水平面从外往内。肌肉：胸大肌 + 肩前束。例：夹胸
  - 水平外展：大臂在水平面从内往外。肌肉：肩后束 + 冈下肌。例：反向飞鸟
- **矢状面**
  - 肩关节屈：大臂从后往前。肌肉：肩前束 + 胸大肌。例：前平举
  - 肩关节伸：大臂从前往后。肌肉：背阔肌 + 大圆肌 + 肱三头（长头）+ 肩后束。例：下背划船
- **额状面**
  - 肩关节外展：大臂从内往外。肌肉：肩中束 + 冈上肌。例：侧平举
  - 肩关节内收：大臂从外往内。肌肉：背阔肌 + 大圆肌。例：宽距下拉

### 股四头肌

- 膝关节伸：膝盖从折叠变为打直。肌肉：股四头肌（股直肌 + 股中间肌 + 股外侧肌 + 股内侧肌）
  - 只有膝伸：器械腿屈伸
  - 膝伸 + 髋伸：杠铃深蹲、哈克机、倒蹬机

### 腘绳肌

- 膝关节屈：膝盖从打直变为折叠。肌肉：腘绳肌。例：俯卧腿弯举、坐姿腿弯举、北欧挺
- 髋关节伸：大腿从前往后。肌肉：腘绳肌 + 臀大肌。例：直腿硬拉、早安体前屈、俯卧髋屈伸

膝伸和髋伸的比例，决定了动作练哪儿：

- **深蹲**：伸膝幅度大、伸髋幅度小，主练大腿前侧
- **硬拉**：伸膝幅度小、伸髋幅度大，主练大腿后侧和臀
- **直腿硬拉**：伸膝幅度最小、伸髋幅度最大，只练大腿后侧

### 臀大肌

- 主要动作模式：髋关节伸（大腿从前往后）。肌肉：臀大肌 + 腘绳肌。动作：杠铃臀桥、绳索后踢、杠铃臀冲
- 次要动作模式：髋关节外展。效率弱于前者——“练臀不练腿”并不划算

### 腹直肌

动作只有两种形式：

- **卷腹**：胸椎、腰椎段弯曲
- **举腿**：骶椎段弯曲，表现为骨盆后旋

常见的误区是仰卧起坐：

| | 卷腹 | 仰卧起坐 |
| --- | --- | --- |
| 脊柱 | 从直变微弯（脊柱屈） | 接近一直打直，缺乏脊柱屈 |
| 髋部 | 大腿和骨盆都不动，没有髋关节屈 | 大腿不动、骨盆前倾，在做髋关节屈 |
| 实际练的是 | 腹直肌 | 屈髋肌群（股直肌、髂腰肌等） |

### 一句通俗记法

往前为伸，往后为屈；再加上肩关节的外展和内收。

## 训练计划与配重

- 找动作可以直接搜动作、肌肉、部位的名字，加一个“教”缩小范围，注意先易后难
- 建议找个朋友一起练
- 每周训练频率：1–2 次是聊胜于无，3–5 次合适有效，6 次是极限，7 次属于自残
- “一周练几次”指平均训练频率，不是一周恰好几轮，也不必练完一轮才能休息，可以临时安排

配重可用「可完成的最大重复次数」（RM）来描述，并非界限分明：

| 目标 | 次数 |
| --- | --- |
| 增力 | 3–5RM |
| 增肌 | 6–12RM（主流） |
| 学动作 | 13–15RM |

更轻的除了热身基本不用。感觉做不动了就放下。

## 我的用法

我现在固定用三分化，一周三到四次，每次先把主项做完再补协同肌群。练之前不再纠结“今天练什么”——按 Day1/2/3 往下轮就行，临时有事就顺延，不追求一周恰好一轮。
