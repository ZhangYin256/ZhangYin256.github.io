这里是**彰隐**的个人主页。

## 技术

- **框架**：[Valaxy](https://valaxy.site/)，基于 Vite + Vue 的静态博客框架
- **主题**：[valaxy-theme-yun](https://valaxy.site/zh/themes/yun)
- **托管**：GitHub Pages
- **部署**：推送到 `main` 分支后由 GitHub Actions 自动构建并发布

站点是纯静态的：没有数据库，没有后端，构建产物就是一堆 HTML、CSS、JS 和图片。

## 内容来源

站内文章整理自我的个人笔记库。笔记按主题挑选、改写后发布，笔记本身保持原样，这里只是它的一个出口。
